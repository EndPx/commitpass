# Event-cover templates

Original artwork generated with the built-in GPT Image tool on 28 September 2026.
Final PNGs are kept here; delivery URLs are in `src/lib/brand-media.json`. Run the
root `scripts/upload-brand-media.mjs` utility to upload these assets to Cloudinary.
The Workshop option reuses the existing generated community workshop photograph.

## Together

The initial direction was mint/cream editorial geometric art: abstract people,
sunburst, arches and circles in forest green, cobalt, orange and peach. The final
image used this cleanup prompt with that generated artwork as the edit reference:

> Finish this event-cover illustration as a completely opaque square printed poster. Keep the simple geometric people, sun and blue/green/orange/peach shapes. Replace ALL transparent, speckled, ragged, multicolored noise between the solid shapes with a single clean solid pale mint-cream background #EDF3DF. Absolutely NO transparency or alpha; every pixel must be opaque. No black empty gaps, no confetti, no debris, no rough contour artifacts. Beautiful smooth flat shapes on lightly textured paper, balanced editorial illustration. Keep no text. Finished opaque artwork fills the square.
