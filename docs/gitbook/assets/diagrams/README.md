# CommitPass documentation diagrams

Two original, editable Excalidraw scenes accompany the documentation overview pages:

- `commitpass-journey.excalidraw`: the six-stage event lifecycle.
- `commitpass-system.excalidraw`: application, contracts, attendance, CRE and indexing responsibilities.

Open the `.excalidraw` files in Excalidraw to edit shapes, labels and arrows. PNGs
are high-resolution documentation previews; SVGs preserve vector rendering and
embed the Virgil font. They were rendered with the official Excalidraw 0.18.1
export utilities. No private credentials or invented performance data are included.

The diagrams describe the current Monad testnet configuration. The external
yield source is a test vault and CRE execution is signed CLI broadcast simulation.
Detailed Mermaid diagrams and implementation boundaries are maintained in the
linked documentation pages.
