# Overview

Using CommitPass starts with the event experience you need. You can browse public events, reserve a spot as a guest, or create and manage an event as an organizer. These guides walk through the application in that order, with the account, token and attendance requirements explained along the way.

## Before your first event

The current app runs on **Monad testnet**. Guests use testnet USDC for commitments and MON for transaction gas. Email or Google sign-in provides account and embedded wallet access through Privy. Testnet tokens have no financial value.

Start with **Getting Started** to prepare your account, wallet and time settings. Then choose the guest or host guide.

## Choose your workflow

| Your role | Main steps |
| --- | --- |
| Guest | Discover an event, review its rules, reserve with USDC, present your QR pass and claim your allocation |
| Organizer | Create the event, manage details and participants, scan arrivals and request lifecycle actions |

For the mechanics behind these actions, read [How CommitPass Works](../introduction/how-it-works.md). For return calculations and exceptions, see [Commitments and Rewards](../protocol/commitments-and-rewards.md).
